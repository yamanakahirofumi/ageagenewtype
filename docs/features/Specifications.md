# アプリケーション仕様書

本ドキュメントでは、Ollama を生成AIエンジンとして統合した IDE 風デスクトップアプリケーションの全体コンセプト、主要機能、および UI/UX の概要について定義します。

## 1. アプリケーション概要

本アプリケーションは、ローカル環境で実行される Ollama を活用し、ファイル編集と AI 対話をシームレスに結合した統合開発・執筆環境を提供します。
一般的な IDE（統合開発環境）のように、ファイル構造の探索、テキスト・コードの閲覧・編集、および AI へのプロンプト指示・対話を1つの画面で完結させることを目的とします。

## 2. 主要機能

| カテゴリ | 機能名 | 概要 |
| :--- | :--- | :--- |
| **LLM 連携** | ローカル LLM 接続 | LangChain4j (`langchain4j-ollama`) を利用してローカルの Ollama サービスに接続し、テキスト生成およびチャット応答を取得。 |
| **LLM 連携** | モデル一覧取得・選択 | Ollama に保持されている利用可能なモデル一覧を取得し、動的に切り替え。 |
| **LLM 連携** | ストリーミング応答 | LangChain4j の `StreamingChatLanguageModel` を通じて生成 AI からのレスポンスをリアルタイムでチャット画面にストリーミング表示。 |
| **IDE風 GUI** | ファイルツリー閲覧 | 指定したワークスペースディレクトリ内のファイル・フォルダ構造をツリー表示。 |
| **IDE風 GUI** | エディタ閲覧・編集 | テキストファイルやコードファイルの閲覧、編集、保存機能を提供。 |
| **IDE風 GUI** | AI チャット対話 | チャット形式でのプロンプト入力、応答表示、および対話履歴の管理。 |
| **コンテキスト連携** | ファイルコンテキスト付与 | エディタで開いているファイルの内容や選択テキストを AI チャットのコンテキストに付与。 |

## 3. GUI構成方針 (IDE風レイアウト)

本アプリケーションの UI は、IDE の操作感に準拠した3分割（または多分割）の `SplitPane` レイアウトを採用します。

1. **ファイルツリー部 (File Tree Pane)**
   - 画面左側に配置。
   - ワークスペースのディレクトリツリーを表示し、ファイルの選択や開く操作を担当。
2. **エディタ部 (Editor Pane)**
   - 画面中央に配置。
   - 選択されたファイルの内容を表示・編集するメイン作業領域。タブによる複数ファイル切り替えに対応。
3. **チャット部 (Chat Pane)**
   - 画面右側（または下部）に配置。
   - Ollama との対話画面。モデル選択ドロップダウン、チャット履歴表示エリア、プロンプト入力欄を備える。

## 4. LLM / Ollama 連携仕様 (LangChain4j)

- **統合ライブラリ**: LangChain4j (`langchain4j-ollama` モジュール)
- **エンドポイント / 通信プロトコル**: デフォルトで `http://localhost:11434` の Ollama サービスへ LangChain4j 経由で接続。
- **LangChain4j 利用コンポーネント**:
  - `OllamaChatModel` / `OllamaStreamingChatModel`: テキスト生成およびリアルタイムストリーミング応答の制御。
  - `OllamaModels`: 利用可能モデル一覧の取得。
  - `PromptTemplate`: エディタのファイル内容や各種変数を組み込んだプロンプトの動的構築。
- **フォールバック処理**: Ollama サービスが未起動の場合や通信エラーが発生した場合は、チャット部にわかりやすいエラーメッセージと再接続ボタンを表示します。
