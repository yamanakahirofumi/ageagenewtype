# 画面詳細設計

本ドキュメントでは、IDE 風のレイアウトを採用したメイン画面における各エリア（ファイルツリー部、エディタ部、チャット部）の配置、コンポーネント構成、および詳細仕様を定義します。

## 1. 画面全体の構成

メイン画面は JavaFX の `SplitPane` を用いて、左右・中央の3つの主領域に分割されます。各領域のサイズはスプリッターのドラッグ操作により伸縮可能です。

```
+-----------------------------------------------------------------------------------+
|  [Menu Bar]  File  Edit  View  Tools  Help                                        |
+-------------------+----------------------------------+----------------------------+
| ファイルツリー部  | エディタ部                       | チャット部                 |
| (File Tree Pane)  | (Editor Pane)                    | (Chat Pane)                |
|                   |                                  |                            |
| ├── src/          | [Tab: main.java] [Tab: prompt.txt]| Model: [ llama3.2 :v ] [v] |
| │   ├── Main.java | -------------------------------- | -------------------------- |
| │   └── ...       | 1 | public class Main {          | [User]: ファイルの内容を   |
| ├── docs/         | 2 |     // ...                   |         要約してください。  |
| └── README.md     | 3 | }                            | [AI]:   以下の通りです...  |
|                   |                                  |                            |
|                   |                                  | -------------------------- |
|                   |                                  | [ Input prompt...      ]   |
|                   |                                  | [Send (Ctrl+Enter)]        |
+-------------------+----------------------------------+----------------------------+
|  [Status Bar]  Ollama: Connected (llama3.2) | UTF-8 | Line 10, Col 5            |
+-----------------------------------------------------------------------------------+
```

## 2. ファイルツリー部の詳細仕様

画面最左部に配置され、ワークスペース内のファイルおよびフォルダの階層構造を表示します。

- **主要コンポーネント**: `TreeView<WorkspaceFile>`
- **主な機能**:
  - **フォルダ展開・折りたたみ**: ルートディレクトリ配下のフォルダ構造をツリー形式で表示。
  - **ファイル選択**: ファイルをダブルクリック（または選択）することで、エディタ部で該当ファイルを開く。
  - **コンテキストメニュー**: 右クリックにより「新規ファイル作成」「ファイル削除」「リネーム」等の基本操作を提供。

## 3. エディタ部の詳細仕様

画面中央部に配置され、選択されたファイルやプロンプトテンプレートの内容を編集・閲覧します。

- **主要コンポーネント**: `TabPane` / `TextArea` (またはカスタムコードエディタ View)
- **主な機能**:
  - **タブ切り替え**: 複数のファイルを同時に開いてタブで切り替え可能。
  - **テキスト編集**: ファイルの閲覧・直接編集、および変更の保存 (`Ctrl+S` / `Cmd+S`)。
  - **コンテキスト送信選択**: 編集中のテキスト全域または選択範囲をチャット部へ送信するアクション（「AIチャットに送る」ボタン/ショートカット）。

## 4. チャット部の詳細仕様

画面最右部（または配置変更可能な右領域）に配置され、Ollama との対話を直接行います。

- **主要コンポーネント**: `ComboBox` (モデル選択), `ListView` / `VBox` (チャットメッセージ一覧), `TextArea` (入力欄), `Button` (送信)
- **主な機能**:
  - **モデル選択ドロップダウン**: Ollama に存在する利用可能なモデル (`llama3.2`, `mistral`, `gemma` 等) を一覧から選択。
  - **対話履歴表示**: ユーザーの発言と Ollama からの AI 応答を時系列で表示。Markdown フォーマットやコードブロックの描画に対応。
  - **ストリーミング応答表示**: AI の生成結果をリアルタイムで逐次追記表示。
  - **プロンプト入力・送信**: `Ctrl+Enter` または「送信」ボタンでプロンプトを送信。コンテキストとして参照中のファイル情報バッジを表示。

## 5. エリア間の連携動作

1. **ファイルツリー → エディタ**: ツリー上のファイル選択イベントにより、エディタ部に新規タブが生成・表示されます。
2. **エディタ → チャット部**: エディタで選択中のテキストやファイルパスを、ワンクリックでチャットのコンテキスト（前提情報）として取り込みます。
3. **チャット部 → エディタ**: チャット部で生成されたコードや修正案を、エディタの開いているファイルへ直接挿入・置換するアクションを提供します。
