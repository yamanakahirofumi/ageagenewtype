## 1. 技術面

### [ ] LangChain4j (langchain4j-ollama) の導入と Ollama 連携レイヤーの実装
- **概要**: LangChain4j ライブラリを用いた Ollama サービスとの統合および通信レイヤーの実装。
- **検討内容**:
    - LangChain4j (`langchain4j-ollama`) の依存関係定義と `OllamaChatModel` / `OllamaStreamingChatModel` の初期化設定。
    - `OllamaModels` を活用した利用可能モデル一覧 (`http://localhost:11434`) の動的取得。
    - `StreamingChatLanguageModel` や `TokenStream` を用いたレスポンスのリアルタイム描画（JavaFX Application Thread への安全な反映）。

### [ ] マルチモデル・オーケストレーションにおける動的モデルスワッピングとメモリ制御の実装
- **概要**: 複数の軽量ローカルモデル（7B〜8Bクラス）を順次ロード・アンロード（スワップ）し、VRAM/RAMの枯渇を防ぎながらパイプラインを実行する制御機構の構築。
- **検討内容**:
    - `OllamaApiService` を拡張し、ステップ変更時における明示的なモデル解放/ロード待ち制御。
    - インストールされていない指定モデルに対するフォールバック戦略（デフォルトアクティブモデルの自動割り当て）。

- **検討内容**:
    - `WorkflowService` におけるアンサンブルステップ結果のパースおよび集計モデル（Aggregator Model）へのプロンプト構成。
    - 相互レビュー時の指摘事項抽出テンプレートと修正特化モデルへのフィードバックルーティングルール。
